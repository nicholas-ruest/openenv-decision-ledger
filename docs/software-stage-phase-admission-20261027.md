This research change preserves the exact reviewed v12 request and runtime. A pure admission function prices every proposed call with the existing reservation formula and 10% margin. Missing quotes, invalid amounts or insufficient remaining allocation reject the whole phase; it never resets a ledger, borrows another allocation or starts calls.
