# Revision-only thinking on ignore-d3: disjoint confirmation passed

The frozen inference protocol showed a gain on its reserved disjoint native software case. This is a private protocol evaluation result, not trained-weight improvement or an Arena leaderboard gain.

| Phase | Thinking off: full / assigned | Revision-only thinking: full / assigned | Full-rate delta |
|---|---:|---:|---:|
| Screen | 1 / 4 | 4 / 4 | +0.75 |
| Reserved disjoint confirmation | 0 / 4 | 2 / 4 | +0.50 |

Confirmation mean semantic reward across all assigned attempts was 0.670833 for control and 0.729167 for treatment, delta +0.058333. Both preregistered criteria passed: positive full-solve delta and nonnegative semantic delta. Control outcomes were three partials and one native execution failure; treatment outcomes were two full solves, one partial and one native execution failure. Failures remain in the denominator.

All eight confirmation assignments and 16 actual requests/replies completed with known usage and independently replayed native outcomes. Each bounded worker shut down cleanly on the recorded boot. Cross-phase call/reply identities were fresh against the selected screen and previous confirmation chunks. No provider, budget, format or truncation failures occurred. All four treatment revisions had nonempty reasoning fields; the other twelve replies did not. No reasoning text or private trajectory is published.

Both arms used identical first prompts, content-only actions, public-field feedback, parent-status reminder, route/model/temperature, interpreter/grader and limits. Both first requests disabled thinking; only treatment revisions enabled it. Maximum confirmation context was 9374; maximum generation plus observations was 6665, within unchanged 24576/8192 limits. The method used more reasoning within the same allowed budget; compute consumption was not equalized.
