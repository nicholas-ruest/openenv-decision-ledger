# Bounded scaffold probe runner

Wires the existing frozen one-response proxy calibration implementation to the separately declared16-call scaffold-only screen: d3/d4, seeds2180000/2180100, four samples each. Raw reset/workspace/request identities are captured before inference and rechecked against actual sampled episode records. Each group has four active workers, no retry; completed raw rows are fsynced before normalization. 27 source dependencies, tokenizer, fresh billing receipt, live pinned DeepInfra route/quote and whole-phase remaining reservations must pass before any model call. Each actual call retains the existing append-before-call reservation guard.

The parent job is bounded to1900seconds and the sampling deadline to1800seconds. Repeated native resets must match before admission. An incomplete or corrupted phase does not yield a passing assessment. Unknown/internal failures stay excluded under provider/internal failure classification with original raw failure retained. Fake not-admitted labels explicitly identify a missing provider call; they are never accepted as valid successful samples.

26 offline tests passed for orchestration, identity/failure handling, complete-phase budget admission and same-prompt assessment. These tests use synthetic mocked responses, not model solves. Actual calibration results are reported separately only after records exist. This is proxy calibration, not training. Hosted checkpoint/thinking and Arena chat equivalence remain unattested; no model improvement or signed Flywheel promotion is claimed. The frozen v12 request and dataset are unchanged.
