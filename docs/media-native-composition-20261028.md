## Limits

The bridge is trusted same-container instrumentation: root access to the server workspace is not a model tool, and this is not an arbitrary remote-container client. A future deployment must attest the actual image and all worker dependencies separately. Killing a local worker only covers its inherited process group; remote provider billing termination is not established. The integration fixture's admitted=True is not a real spending authorization: it contains no provider route and never touches private reservation ledgers.

This tests component integration and failure accounting rather than adding evidence about task difficulty, curriculum benefit or ranking. Native sessions created for prefix replay are controls, not independent model prompts or model samples. No new inference, training, dataset replacement or Arena submission occurs. Softwarev12 and media-v13 remain frozen and unapproved; actual model-phase admission still requires fresh private billing reconciliation and existing whole-phase accounting guards.
