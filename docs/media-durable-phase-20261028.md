## Execution limits

The admitted flag is a dependency supplied by an external whole-phase gate, not budget authorization. Existing private ledger reconciliation, provider fingerprinting and complete-phase reservation admission remain mandatory. No model phase has been admitted or executed.

The core checks a finite wall deadline of at most1800seconds before and after external operations and before further dispatch. It cannot interrupt an indefinitely blocked callback. A real execution adapter must supply bounded HTTP/native operations plus process-group supervision/cleanup; this change does not establish remote billing termination. Late returned raw data is preserved, but no native action or next provider call follows it. Completed prefixes are replayed for validation, so a future adapter must budget native replay time and handle nondeterministic shell output conservatively.

A process crash may leave intent-only or raw-only evidence; existing external reservations still count and no automatic retry or resume is authorized.
