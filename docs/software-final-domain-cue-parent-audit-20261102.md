# Leased read-only parent audit

`parent_audit.audit(output, counter, args)` connects the existing case-bound Native archive reconstruction, local reservation/supervisor consistency checker and pinned MetaHarness reconstruction assessment. Existing immutable case/source/inventory gates run before argument-dependent private reads or Native construction. A caller-supplied audit bundle must match its exact SHA-256, original source/method inventory, case receipt and archive path. The bundle carries exact file/hash leases for the complete archive and its original supervisor siblings, retained before/after ledger bytes and frozen route prices.

The audit snapshots and verifies every declared artifact, rejects omitted or unexpected files and checks the unchanged retained ledger prefix. It invokes the original independent Native assembler. A complete phase must also pass original process/deadline/shutdown, records, unique reply identities, reservations and quotes before the unmodified pinned MetaHarness `fitness.mjs:scoreCell` is called through the prepared assessor. An incomplete phase retains all eight assignments but receives neither custody success nor fitness/terminal credit. Every input file and the artifact inventory are rechecked after analysis; changed inputs refuse the result.

This is integrity and local consistency, not provider authentication. Supplying a matching JSON hash cannot establish current account credit, root spending or provider usage. Both component and aggregate results keep provider provenance, actual credit, root attestation, execution, selection, confirmation and improvement false. No provider is constructed; no ledger, receipt, account observation or counter is changed. The adapter is not wired to launch inference or open confirmation.

Six integration tests passed locally using explicit synthetic leased artifacts and **mocked Native reconstruction**. The positive complete-path test executes the actual pinned MetaHarness assessor. Other checks cover public refusal before private reads, bundle/artifact mutation before reconstruction, mutation during reconstruction, missing manifest files and incomplete unknown usage without fitness. These tests do not replace full Native/supervisor qualification or validate actual model responses. The seven custody and eight reconstruction regressions are separate controls.

The adapter is included in the immutable method inventory. All public execution seals remain unset. The revised combined source still requires full qualification under the original supervisor, independently leased real artifacts and all actual admission requirements. No new case or confirmation manifest is chosen by this change; prior closed studies, frozen requests, original resource bounds and protected financial/provider/supervisor sources remain unchanged. No training or model/leaderboard gain is claimed.
