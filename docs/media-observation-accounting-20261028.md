## Limits

This fixes the missing observation term in a local proxy-accounting implementation. It does not establish Arena's unknown production chat template, special-token overhead, hidden reasoning representation or exact server accounting. The serialization and tokenizer pin are explicit so future measurements can be reproduced rather than called production-equivalent. The existing local calibration helper itself describes canonical message context as an approximation. arena_wrapper_equivalent stays false.

The existing provider-generation-only core and saved fixtures remain unchanged for provenance. Only this new variant is observation-aware. It has no provider implementation or paid CLI; no phase is admitted by this change. Existing private reconciliation, whole-phase budget checks and append-before-call reservations remain mandatory. No new model calls, training, native image experiments, task/curriculum changes, dataset replacement or Arena submission occurred. Both reviewed candidates remain frozen and unapproved. Real model improvement is unmeasured.

This was CPU/local accounting integration, not a native-container or model experiment; no real provider reservation was made. Both old and revised isolated checkouts/reports were retained.
