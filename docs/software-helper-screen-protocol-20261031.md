# Separate declared-helper preservation screen

This candidate restores only the two glob helpers explicitly declared complete in the public task contract. It leaves repair targets to the model. It does not combine public-example finalization with helper preservation. The earlier finalization candidate failed disjoint confirmation and remains closed.

The helper screen uses four interleaved samples per arm on one independently audited new procedural case, with identical initial prompts, route, temperature and response format. The baseline keeps the original two-response revision protocol. The treatment applies only the declared-helper controller. Truncated text is never recovered. Controller edits are identified separately from actual model responses, and every Native observation and controller receipt consumes the original completion allowance.

The finite worker delegates the existing financial backend, amendment-bound reservation gate and Linux deadline supervisor. It introduces no spending cap, token source, route override or retry. The full sixteen-call worst case is quoted before each fresh two-attempt chunk. Prior chunks must independently replay before a later chunk can proceed. Existing worker argv and a host-wide helper lock prevent duplicate helper launches. The fixed 23:00 Toronto stop remains in force.

Production entry points are sealed by a source constant set to `None`. Sealing requires an immutable private case audit linked to the preceding complete case inventory and exact method hashes, followed by a separately tested clean source revision. A command-line argument, environment variable, reconciliation boolean or successful qualification cannot replace the seal. Confirmation is absent from this worker and remains blocked pending a helper-specific positive-screen gate.

Independent assembly binds raw reserved/called/replied identities, exact original assignments, case lease and execution-source hashes. It regenerates Native/controller trajectories and costs from original replies. All eight assigned attempts remain in the denominator, including unknown usage, failures and unexecuted assignments. Incomplete evidence suppresses MetaHarness fitness. Complete evidence uses the existing hash-checked MIT MetaHarness `fitness.mjs:scoreCell` at `b8c3d38de41203faf633ef6dceb8452a4727b0ea`. Positive full-solve delta and nonnegative semantic delta, without execution/provider/budget failure, select a screen for fresh disjoint confirmation; they do not establish model improvement.

Qualification uses only already-used case 3100000 (and 3080000 for inventory-overlap checks), scripted responses and temporary fault-injection archives. Tests cover Native helper restoration, actual transcript and observation costs, changed identities/source leases, denied reservations, unknown usage after known replies, incomplete phases, fixed deadlines, actual local process supervision and default refusal before backend construction. Synthetic live-path controls are explicitly mocked and are not provider evidence.

There are no new model or leaderboard results in this protocol implementation. Managed-actor portability remains unproven. This is controller research, not GRPO training, an Arena submission or an HF dataset replacement. Frozen v12 is unchanged and unapproved.
